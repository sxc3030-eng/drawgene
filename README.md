# drawGene

Logiciel de dessin technique 2D / 3D qui s'installe comme une application (PC, Android, iPhone) et fonctionne hors-ligne.

**👉 Ouvrir et installer : https://sxc3030-eng.github.io/drawgene/**

- Plans de maison : murs, portes, fenêtres, pièces, surfaces
- Liste de matériaux et coûts (2x4, 2x6, gypse, isolant, béton, plancher…)
- 3D paramétrique : extrusion, révolution, trous, motifs, mesure 3D
- Reconstruction d'une pièce depuis une photo (feuille A4 comme référence)
- Masse et coût des pièces mécaniques
- Import STEP / IGES / STL / OBJ / DXF, export DXF / STL / OBJ / PNG / CSV
